# Screens

- **Foundations:** responsive examples for color, typography, shape, motion, icons, brand and adaptive layout.
- **Component catalog:** search and group navigation, lazy desktop and phone previews, generated props table, and persona-scoped review form.
- **Sketches:** screen wireframes on an infinite canvas (`@protoyard/views-ui/canvas`, loaded only when the section opens): a sketch picker, a "New sketch" form for designers, and the canvas editor (shapes, sticky notes, frames, connectors; keyboard: Tab between shapes, arrows move them). Read-only for other roles.
