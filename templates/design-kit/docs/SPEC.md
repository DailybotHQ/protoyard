# Design Kit specification

This template provides a local design-system reference workspace. Its routes are represented by Foundation and Component Catalog sections in the single-page shell. It does not require a backend or load remote assets.

## User flows

- Browse color, type, shape, motion, icon, brand and adaptive foundations.
- Search component entries, open their responsive desktop and phone previews, and inspect source-derived props.
- Save a review status and note for an entry. The designer can write; the stakeholder scenario is read-only.
