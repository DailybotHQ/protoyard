# Flows

## Complete a lesson

1. The enrolled learner chooses **Mark complete** for a lesson.
2. `lessons.complete()` asserts `lessons:complete` and validates the lesson id.
3. `environment.run()` applies the selected scenario's network behavior.
4. A Dexie transaction confirms enrollment and writes an idempotent progress row
   with `clock.now()`.
5. The catalog updates through `liveQuery` and reports completion.

## Submit a quiz

1. The learner selects an option for every question and submits.
2. `quizzes.submit()` asserts `quizzes:submit`, validates the quiz id and
   answer indexes, then checks enrollment.
3. The service grades the submitted choices against the stored answer key and
   records score, pass state, answers and simulated submission time in one
   transaction.
4. The result and latest saved attempt appear in the course catalog.

## Review a cohort

1. The instructor opens the Instructor overview.
2. Course enrollment and lesson progress feed the lazy chart.
3. Cohort sessions generated by `schedule()` are listed in simulated-time order.
