# Pebblestat Analytics: permissions

Simulated permissions: UX only, not security. Services enforce them with
`session.assert`, so a forbidden action fails even when the UI is bypassed.

## Record-level rules

<!-- protoyard:generated:rules -->
_No record-level rules._
<!-- /protoyard:generated:rules -->

There are no policy rules. Ownership is enforced in `src/domain/services.ts`: without the `…:manage-all` capability, renaming or deleting a report, segment, alert or annotation requires `ownerId` (or `authorId`) to be the actor's persona id. Owners hold every capability through `*`.
