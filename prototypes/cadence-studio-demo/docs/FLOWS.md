# Flows — Cadence Studio

## Create and reschedule a booking

1. Open **Bookings calendar**.
2. Select an empty date/time slot. The form starts with that slot. Cadence Studio schedules one-hour sessions.
3. Enter a title and submit. The generated booking service validates, runs through the simulated environment and persists the record transactionally.
4. Focus the booking event and press Space to grab it. Arrow keys move by 15 minutes or a day; Enter saves, while Escape cancels. A pointer drag also moves an event.

## Inspect booking details

Select an event to open its generated booking detail route. The overview shows its stored fields; the activity tab shows generated service history.

## Change appearance

Open **Settings**, choose a theme and color mode. Appearance is saved for this browser and survives a reload.

## Read-only view

Open the `viewer` scenario. The generated policy allows inspection while hiding create and update actions.
